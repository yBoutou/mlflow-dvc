# Commentaire

Ce fichier contient des notes et commentaires sur le projet **mlflow-dvc**.

## Description du projet

Ce projet combine deux outils puissants pour le suivi et la gestion des expériences de machine learning :

- **MLflow** : suivi des expériences, des métriques et des modèles ML
- **DVC (Data Version Control)** : versioning des données et des pipelines ML

## Notes

- Assurez-vous d'initialiser DVC avant de lancer les pipelines (`dvc init`)
- Les expériences MLflow sont loggées automatiquement lors de l'exécution
- Les artefacts et données sont versionnés via DVC
